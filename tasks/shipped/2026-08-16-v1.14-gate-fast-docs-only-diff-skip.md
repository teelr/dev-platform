# v1.14 Gate-Fast Docs-Only Diff Skip

v1.14 Gate-Fast Docs-Only Diff Skip, **closes v1.14** (2026-08-16, PR #69, `tasks/gate-fast-docs-only-skip-spec.md`): closes [issue #68](https://github.com/teelr/dev-platform/issues/68), filed after kermit-v3 (PR #367) and Keystone's own gate independently proved the same docs-only-diff skip live the same day — `/gate fast`'s expensive checks (test suites, lint, build) exist to verify code, so a diff that changes zero code files was still paying the full wall time. Ships `scripts/lib/docs_only_diff.sh`, a reusable detector (diff vs. `main` unioned with uncommitted changes, matched against an overridable doc-path allowlist), wired into dev-platform's own `scripts/gate_fast.sh` as the reference implementation — skips the auto-discovered test-suite loop on a docs-only diff, lift checks (taxonomy, syntax, secrets, live verify) always still run. Ships as a documented pattern in `docs/RULE_RATIONALE.md` (new "Gate-Fast Docs-Only Diff Skip" section) rather than a shared script, since `gate_fast.sh` has no runtime distribution mechanism unlike the CI YAML template. `/review` caught a real bug: bash's `*.md` matches any `.md` file at any depth, which would have wrongly classified `commands/*.md` as docs even though `tests/commands/frontmatter.sh` validates those files live — fixed by narrowing dev-platform's own allowlist explicitly, documented in three places for future adopters. 7-assertion `tests/docs-only-skip/` suite covers the cross product (committed/uncommitted, docs-only/mixed, empty diff, both override knobs); one weak assertion (base-ref override that didn't actually discriminate a broken implementation) caught and fixed at self-review, live-verified by temporarily hardcoding `main` into a scratch copy and confirming exactly that assertion flips to FAIL. Gate at 235 PASS (+7). Single-Phase spec per the branching decision rule. Released `v1.14`, milestone #25 closed. Post-merge filed handoff issues on `keystone_prototype`/`SQRL`/`OPIE`/`kanban` (+ FYI on `keystone`, which already had an equivalent) so each ports the pattern from its own session.
