# v1.17 Duplicate Number Check

v1.17 Duplicate Number Check, **closes v1.17** (2026-08-21, `tasks/duplicate-number-check-spec.md`, closes [issue #75](https://github.com/teelr/dev-platform/issues/75)): kermit-v3 PR #481 (2026-08-21) hit a real collision when two in-flight PRs both claimed `tasks/HARNESS_HANDOFF_QUEUE.md`'s Ask #51 (merged with zero text conflict — different line positions, a silent semantic duplicate) and `tasks/lessons.md`'s L60 (a real git conflict, but resolving it correctly — renumber the loser, sweep every cross-reference — was a manual judgment call, not something tooling verified). Unlike `check_version_collision.py`'s claim-ahead-of-time approach, neither number has a live external arbiter (no GitHub milestone to ask) — the collision only becomes real at merge time, so the fix is the simpler shape the issue itself proposed: a mechanical duplicate-number check run at gate time. Ships `scripts/check_duplicate_numbering.sh`, two independent passes each a graceful no-op when its target file is absent or unused: (1) any markdown table headed literally `| # | ... |`, flagging duplicate first-column values only WITHIN one table's data rows — critically NOT a whole-file scan, verified live against kermit-v3's real, current file that raw values `#39` and `#37` each legitimately repeat across two DIFFERENT independently-numbered tables today, which a naive whole-file grep would falsely flag; (2) `## L<N> —` lessons.md headers, checked for duplicates globally across the file. Exact-string comparison also correctly leaves intentional variants alone (kermit-v3's real `46` vs. `46R`, a documented regression follow-up, never collide). Verified before assuming uniformity, per the issue's own caveat: kermit-v3 has 5 `#`-headed queue tables, Keystone has 4 (missing kermit-v3's specific Ask table; its outbound-communiques table has no `#` column), kermit-pa's queue file has **zero** `#`-headed tables at all (a completely different shape) — only its lessons-L# convention matches. Wired into dev-platform's own `gate_fast.sh` as the reference implementation (graceful no-op locally, since dev-platform has neither convention). Documented in `docs/RULE_RATIONALE.md`'s Kermit-Specific Rules section rather than `CLAUDE.md`'s Gate Tiers — this pattern is consumer-specific, not universal to every project's gate (unlike the docs-only-diff skip), the same treatment `check_version_collision.py` already gets (no `CLAUDE.md` mention at all); `CLAUDE.md` line 5's existing `RULE_RATIONALE.md` pointer-list gained one clause instead. 8-assertion `tests/duplicate-numbering/` suite, including the load-bearing `cross-table-queue.md` regression guard proving same-number-different-table reuse is NOT flagged. No spec deviations. Gate at 244 PASS (+9). Released, milestone #28 closed.
