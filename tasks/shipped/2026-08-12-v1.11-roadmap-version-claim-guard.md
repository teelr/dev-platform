# v1.11 Roadmap-Version Claim Guard

POST`. Single-PR spec (all 3 Spec Phases) per the branching decision rule. Released `v1.11`, milestone #21 closed. **Its regex only matched kermit-v3's heading-form `ROADMAP.md` convention, silently providing zero protection against dev-platform's own list-form convention — fixed same week in v1.12.**
