`/merge` post-merge chore-branch worktree isolation fix (2026-08-20, `tasks/merge-post-merge-chore-worktree-isolation-spec.md`, closes [issue #73](https://github.com/teelr/dev-platform/issues/73)): Step 7 sub-step 6's `chore/<slug>` post-merge branch (cut when a project forbids direct commits to `main`) was always created in the shared main checkout, even on worktree-opted-in projects — reopening the exact contamination race worktree isolation exists to prevent for the one kind of commit `/merge` itself makes. Frontmatter `allowed-tools` gained `EnterWorktree` alongside the existing `ExitWorktree`.
