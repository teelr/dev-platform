# "Keep it verbatim" means copy from the source, never reconstruct from memory

v1.24's spec said to keep planning.md's taxonomy-migration note verbatim through the rewrite. My earlier read of that section had been truncated mid-mapping ("R3→v..."), and I wrote the rewrite by reconstructing the rest — inventing `R4b→v0.5, R5→v0.6` where the real mapping was `R2→v0.5, R4b→v0.6, R7→v0.7, R6→v0.8, R5→v0.9`, and dropping two sentences entirely. Caught only because the spec's own checklist said verbatim, which prompted `git show HEAD:planning.md` to diff against. A truncated read followed by a fluent reconstruction looks exactly like a faithful copy; when a task says preserve, fetch the original from git or the file at full width and paste it — never type it back from recall.
