# Synthetic test fixtures must use PAST timestamps. v0.5 Phase 3's /test built…

Synthetic test fixtures must use PAST timestamps. v0.5 Phase 3's /test built an end-to-end fixture covering every metric path — initially using timestamps like `2026-05-11T09:00:00` while current local time was ~05:00. The aggregator's window filter (`ts > until`, where `until = now`) silently dropped all 12 fixture events. Surfaced as "event_count = 0" in the first assertion. Fix: backdate fixture timestamps (e.g., `2026-05-10T...`) so they fall inside any reasonable `--period` window. Pattern: when writing time-bounded test fixtures, anchor timestamps to a known-past date (or compute relative to "now" minus an offset); never use today-but-future times. The aggregator's `--period all` does NOT mean "ignore the upper bound" — it means `since=datetime.min`, but `until` is always `now`.
