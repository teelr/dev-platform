# When changing a file format, grep for the filename itself — not just references to it

v1.23 moved `tasks/lessons.md` to a `tasks/lessons/` directory. The spec's File Change Summary listed `scaffolding/*/CLAUDE.md` because those files *mention* `lessons.md` in a directory-tree comment — but it missed `scaffolding/*/tasks/lessons.md`, three real stub files the templates ship. Every newly scaffolded project would have been born with the old colliding table, so the fix would have silently not applied to exactly the projects most likely to hit the problem later. Found at `/code` time with `find scaffolding -name "lessons*"`, after a `grep` for the *string* had already come back looking complete. Grepping for references finds the documentation; only globbing for the filename finds the artifacts.
