# Specs that change a script's output contract MUST include a Change that…

Specs that change a script's output contract MUST include a Change that updates the regression-test suite asserting that contract. v0.5 Phase 1 Change 2 migrated `hooks/post-tool-heartbeat.sh` from text format (`tool=Bash`) to JSONL, but the spec didn't list updating `tests/hooks/post-tool-heartbeat/run.sh` (the v0.4 regression suite) as a Change. The omission surfaced when gate_fast went red mid-/code with 4 FAILs on the heartbeat fixture suite — implicit, not explicit. Pattern: when a /plan Change rewrites the output format / API / event shape of an artifact that has a downstream test, the spec MUST also list a Change to update that test in lockstep. Going forward, /plan reviews check every output-changing Change for a paired test-update Change.
